# Интернет-магазин на Vue

Контрольная работа: каталог товаров с поиском, фильтрацией и корзиной. Всё приложение — один файл
`src/App.vue` (Vue 3, Composition API, `<script setup>`).

## Запуск

```bash
npm install     # установка зависимостей
npm run dev     # запуск (http://localhost:5173)
npm run build   # сборка + проверка типов
```

## Что сделано

- **Каталог** — 8 товаров из массива `products` в `src/App.vue`.
- **Поиск** — поле «Поиск товаров» (по названию).
- **Фильтр** — выбор категории (Все / Электроника / Аксессуары / Одежда).
- **Сортировка** — по цене: сначала дешёвые или сначала дорогие.
- **Корзина** — добавление кнопкой «В корзину», удаление крестиком, кнопка «Очистить корзину»,
  количество товаров в заголовке и итоговая сумма.
- **localStorage** — корзина и промокод сохраняются после обновления страницы.
- **Промокод `WEB`** — скидка 10%: цена каждого товара уменьшается на 10 %, пересчитываются
  суммы позиций и «Итого», старая цена показывается зачёркнутой.

## Как проверить

1. `npm run dev` и открыть страницу.
2. Ввести в поиск `ноут` — останется один товар; ввести `zzz` — «Ничего не найдено».
3. Выбрать категорию «Одежда» — 2 товара. Выбрать сортировку «Сначала дешёвые».
4. Добавить «Ноутбук Pro 14» (89 990 ₽) и «Кружку разработчика» (690 ₽) два раза →
   «Итого» = 91 370 ₽.
5. Ввести промокод `WEB` → кружка 621 ₽ вместо 690 ₽, «Итого» = 1 242 ₽.
6. Обновить страницу (F5) — корзина и промокод сохранились.
7. Удалить позицию крестиком, затем «Очистить корзину».
